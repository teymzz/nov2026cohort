# Weekend Assignment [12-11-2026]

1. Create a word sensor application using any four vulgar words (e.g stupid, crazy, ... e.t.c) 
2. When a sentence is entered into the text field that contains any of the vulgar words, the word 
must be properly filtered. 
   - For example if the vulgar words are ``` idiot```, ```stupid``` and sentence entered is : 

     > This is an idiot and stupid person. How can he act like an idiot.

    Then the final sentence after filtering should be:

    > This is an id*ot and stup*d person. How can he act like an id*ot.

3. Your final output should be displayed on the webpage not the console. 
4. Make your word censor app attractive with a modern UI/UX  design.
5. Upload your work to github and submit on the Javascript group along with all previous assignments.
6. Prepare for a practical class on Monday.
